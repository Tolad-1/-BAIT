How to use the recommendation

Push LTL: weather indicators are below the screening thresholds, so smaller loads may move without waiting solely for weather.

Wait / consolidate: elevated precipitation, snow, low visibility, or wind raises delay and handling risk. Hold non-urgent LTL where practical and build a full truck.

Crop selection changes the risk tolerance used by this simple screening rule; it does not change the weather forecast. Confirm carrier capacity, road restrictions, local advisories, loading-site conditions, and customer urgency before dispatch.

Data source and storage

Source: Open-Meteo forecast API for the current year and Open-Meteo Historical Weather API for 2024–2025. Requests use the selected hub's latitude/longitude.

Fields: weather code, precipitation probability, snowfall, visibility, wind speed, and temperature. Units are shown in the dashboard.

Where stored: this page keeps the API response in JavaScript memory only while it is open. It does not write weather data to a server, database, cookie, or local storage. Reloading the page fetches fresh data.

County choices are representative Minnesota dispatch hubs, not official county boundary centroids. A single point forecast may not represent every road or farm in a county.

Weather data provided by Open-Meteo. Forecast values and API availability can change. This file needs an internet connection to retrieve weather.
